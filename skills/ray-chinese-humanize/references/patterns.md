# 中文 AI 腔模式表

这份表用于深度改写或诊断。不要把它当成绝对禁词表；看密度、上下文、语体和是否承载信息。

## 1. 常见中文套话

| 模式 | 例子 | 处理方式 |
|---|---|---|
| 背景开场 | 在当今时代、随着……不断发展 | 从文章真正的问题或事实起笔 |
| 价值拔高 | 具有重要意义、开启新篇章、里程碑 | 写清具体影响、限制或删掉 |
| 商业黑话 | 赋能、抓手、闭环、协同、提质增效 | 换成动作、责任主体和结果 |
| 伪客观 | 专家认为、业内普遍认为、大家都知道 | 给出真实来源，否则删掉 |
| 空泛结尾 | 未来可期、让我们拭目以待、值得期待 | 回到文章中的具体判断 |

## 2. 句式与结构

- 二元对比壳：`不是 A，而是 B`、`不仅 A，更是 B`。如果不是必要的真实对比，直接说 B；如果两边都重要，分别说明关系。
- 讲义式冒号：`原因很简单：`、`重点是：`、`我的结论是：`。若冒号后是具体清单可以保留；若只是制造悬念，改成普通句。
- 三段式堆叠：连续三组并列名词、三段相同长度、`首先/其次/最后`。保留真实三项清单，删除虚凑的第三项或改成自然叙述。
- 伪洞察提示：`真正、其实、本质上、核心在于、关键在于、归根结底`。删掉后检查判断是否仍然成立。
- 命令模板：`别急着……先……`、`顺序别反了`、`记住这句话`。改成具体观察、风险或事实。
- 机械互动：`你是否也……`、`让我们一起……`、`希望这篇文章能……`。没有真实交流目的就删掉。

## 3. 翻译腔与弱动词

- `对于 X 来说`：多数情况可改为“X”。
- `围绕 X 展开讨论`：改为“讨论 X”。
- `通过……实现……`：明确行动者和动作；例如“团队通过优化流程实现效率提升”可改为“团队改了流程，处理时间缩短”。只有原文有结果时才写结果。
- `使得……得以……`：改为直接动词。
- `进行了深入分析`：改为“分析了”，若有深度证据再保留“深入”。
- 抽象名词过密：`推进、建设、提升、优化、实现、开展、完成` 连续出现时，寻找具体对象、动作和后果。

## 4. 信息与可信度

- 模糊指代：`这件事、这些、这个方向、某种程度上`。读者需要知道对象时补回具体名词。
- 无来源归因：`数据显示、研究表明、用户普遍认为`。没有来源就降低断言或删掉归因。
- 结论超出证据：把“可能、相关、观察到”改成“证明、必然、彻底解决”。必须恢复原有强度。
- 经验缺失：文章只有概念，没有“我测了什么、条件是什么、遇到什么问题、结果怎样”。不能编造细节，只能标出信息缺口。

## 5. 节奏与排版

- 句长过于均匀：重排信息，让关键判断有短句，解释有长句。
- 段落过于整齐：不要把每段都改成“观点—解释—总结”的同一模版。
- 标点堆叠：连续冒号、分号、破折号、括号或粗体标题。按信息关系改为句号、逗号或普通段落。
- 过度列表化：列表项只是裸名词时，改成带动作和结果的句子；真正的参数表、步骤表和清单不要改成散文。
- 假口语：故意加入“说白了、你细品、哈哈、家人们”、错别字或碎片句。没有原文依据时不要添加。

## 6. 文体保护

- 技术文：优先准确、可复现、术语统一；不要强行活泼。
- 评论文：保留立场、判断和必要的锋利感；不要把观点洗成中性总结。
- 公众号/博客：可增强节奏和具体感，但不强行添加钩子、鸡汤或互动结尾。
- 产品文案：保留卖点，但每个卖点尽量有对象、动作、差异或结果；删除无证据的“领先、颠覆、全方位”。
- 学术/报告：保留规范术语、限定词、引用和谨慎语气；只清理明显套话和翻译腔，不把论文改成口语。

# 外部资料阅读入口

把第三方资料作为“索引入口”接入现有知识库，而不是把外部内容伪装成本地原创内容。默认产出一个 Markdown 说明页，保留原作者、原始链接、资料类型、阅读价值、推荐顺序和本地笔记入口。

## 工作流程

1. **确认资料**：打开用户提供的 URL，确认标题、作者/组织、资料类型、主要内容和官方阅读方式。无法访问时保留用户给出的标题和链接，并标注“待核验”。
2. **选择目录**：优先放入现有知识库中与主题最匹配的目录；不要新建泛化的 `misc`、`downloads` 或 `第三方资料`。若已有同主题目录，沿用它。
3. **决定复制范围**：默认只创建说明页和链接。只有用户明确要求做本地摘录、课程化改编或离线存档，并且授权/许可允许时，才复制必要片段；复制内容必须保留出处、版权和原文链接。
4. **创建入口页**：文件名使用主题化、稳定的英文或拼音短名，例如 `fde-guidance-book.md`。页面至少包含：标题、作者、资料简介、原文链接、官方阅读方式、推荐阅读顺序、与本地知识库的关系、笔记入口和版权/使用说明。
5. **接入目录**：在所属目录的 `README.md` 或导航页增加入口链接，避免资料只能通过文件搜索发现。
6. **检查链接**：确认本地相对链接有效，外部链接指向原始仓库或官网；不要把临时搜索结果页当作资料链接。

## 默认模板

```markdown
# <资料标题>

> <一句话说明资料是什么，以及为什么值得阅读>

## 原文入口

- 在线阅读：[<原始资料名称>](<原始 URL>)
- 官方网站/下载：[...]（如有）

## 内容简介

<基于原文 README 或官方页面的简短介绍，不新增未经核实的事实。>

## 推荐阅读方式

1. <入口或自序>
2. <核心章节/部分>
3. <案例、附录或实践部分>

## 与本项目的关系

<说明它与当前课程、知识库或项目的关联。>

## 我的学习笔记

- <待补充的本地笔记或相关资料链接>

## 版权与说明

本页仅作为阅读索引。正文版权归原作者或原项目所有；引用、转载和改编请遵循原项目的许可证与版权声明。
```

## 取舍规则

- **链接优先**：原资料持续更新、内容完整、用户主要想阅读时，只做说明页和跳转链接。
- **本地摘录**：用户要把资料融入课程、做摘要或记录个人批注时，只保存必要的摘要、学习笔记和引用，不复制全文。
- **本地镜像**：仅在明确的离线需求、许可允许且有维护计划时使用；页面中注明来源、版本/日期和同步方式。

## 边界

- 不把第三方内容写成当前项目原创内容。
- 不删除原作者、原仓库、许可证或版权信息。
- 不为了“直接可看”复制整本书；优先让用户通过原文入口阅读最新版。
- 如果资料是代码仓库，除非用户要求集成代码，否则不要把它嵌套克隆进当前 Git 仓库，以免引入嵌套 `.git`、同步和许可证问题。

# Ray 海豚信息图

## 目标

把一份内容压缩成“读者滑动即可读懂”的单张长图：事实具体、文字占主导、层级清楚、来源可追溯，并且不泄露私人或内部信息。默认输出 1024×1536（3:4）PNG；除非用户另有要求，不制作日历、邮件检查、API 余额等个人工作流面板。

## 工作流

### 1. 提炼可公开的内容

先把原文整理成 4–5 个主题卡片，每张卡片包含：

- 一个短标题（对象 + 变化/结论）；
- 2–4 条具体事实（数字、时间、功能、限制或案例）；
- 一条“行动｜……”建议；
- 需要时附官方来源链接或来源名称。

把推测、营销口号和已核实事实分开。数字必须能从输入或可靠公开来源核验；不确定时改成定性表述并标注“待核验”，不要补造精确数字。

### 2. 做公开分享脱敏

在进入版式前删除或泛化：邮箱、订单/发票、金额、账号、验证码、令牌、内部域名、私人链接、个人日历事件、未读邮件状态、API 余额、客户姓名及任何可回溯到个人的组合信息。公开报道中的公司名称、产品名称、发布日期和统计数字可以保留，但不要把私人上下文写进图里。二维码只指向用户明确提供的公开 URL。

### 3. 设计文字主导版式

默认采用白底、深石墨文字、橙色强调的编辑型版式：

1. 左上角放品牌标记，例如“海豚智脑”，其右侧可放小号网站 `hub.smarphin.com`；不要让网址抢过标题。
2. 顶部放日期（仅当它是内容发布日期，不要放个人日程日期）、大标题和一行副标题。
3. 用 01–05 编号卡片组织主题；左栏放主题，右栏放要点，底部放橙色“行动｜……”条。
4. 底部放一句可独立转发的总结文案；若有二维码，将总结与二维码在同一水平带内垂直居中，二维码靠右且不加厚边框。
5. 文字约占画面 80–90%，图标只作辅助（通常不超过 8% 面积）。优先保证手机端可读性、足够留白和一致的行距。

### 4. 生成与合成

使用 `imagegen` 生成背景、卡片、中文排版和品牌标记时，提示词必须包含：画布比例、具体文案、字号层级、配色、禁止抽象图标堆砌、禁止新增文字。生成后可用 Pillow 做像素级合成和校正。

二维码不要交给图像模型绘制。运行 `scripts/make_branded_qr.py` 用确定性 QR 库生成，再合成到信息图右下角。推荐深石墨模块、橙色小面积点缀、保留四角定位块和白色静区；中心装饰只能很小，必须保持可扫描。网址可作为二维码下方的小号说明文字。

### 5. 发布前检查

- 从上到下通读：中文无错别字、数字/单位一致、标题与卡片结论对应；
- 用 OCR 或人工检查确认没有私人信息、内部链接或“公开分享版”等不必要字样；
- 在手机尺寸预览，确认正文不是大片图标或过小灰字；
- 解码二维码，确认 URL 正确且周围留有静区；
- 确认输出为 PNG、比例为 3:4，文件名使用主题化英文短名；
- 同时保存可编辑的源文案/提示词，便于下一期沿用模板。

## 默认提示词骨架

```text
制作一张 1024×1536、3:4 的中文纵向信息图，面向公开社交媒体分享。
品牌左上角：海豚智脑｜hub.smarphin.com。
白底、深石墨黑正文、橙色强调；编辑型信息卡，不要大片 icon，不要日历、余额、邮件检查或任何个人信息。
标题：<具体标题>；副标题：<范围/结论>。
按 01–05 排列，每卡片包含“主题标题 + 2–4 条具体事实 + 行动｜一句建议”。
底部是一句总结，右侧预留二维码位；不要自行新增、改写或拼错中文文字。
```

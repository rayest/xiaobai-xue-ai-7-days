# Ray Projector Deck 视觉与组件规范

## 基础尺寸

- 页面宽度：`min(1280px, 96vw)`。
- 页面高度：`min(70vw, 720px)`，打印时切换为横向整页。
- 页面内边距：桌面约 `48px 64px 70px`，移动端约 `30px 26px 65px`。
- 页脚固定在底部，左侧放本页结论或来源，右侧放 `当前页 / 总页数`。

## 组件选择

- 3 个观点：三列 `.grid` 卡片。
- 4 个观点：两列 `.grid.two` 卡片。
- 顺序或闭环：`.flow` 流程节点，节点之间使用箭头。
- 对照、事实和验收：`.matrix` 表格。
- 代码、目录、配置：`.codebox` 等宽代码块。
- 需要观众记住的核心判断：`.quote` 左侧青绿线。
- 概念密度高的页：使用深色 `.dark`，但保持信息量克制。

## 页面节奏

- 开场页必须有一个可引发现场回应的问题。
- 连续两页不要使用完全相同的组件布局。
- 每 4—6 页安排一页深色重点页、反例页或案例转折页。
- 内容页的标题尽量是结论句，而不是单纯名词。
- 一页的主要视觉焦点不超过三个；复杂表格必须减少正文段落。

## 投屏与打印

- 正文最小字号建议 16px；代码和表格不要小于 14px。
- 普通页不依赖悬停状态才能理解。
- 打印隐藏顶部控制、导航、讲师提示和进度条。
- 打印页面必须保留背景色：使用 `print-color-adjust: exact`。
- 手机端流程改为纵向，表格改为单列或允许纵向阅读。

# 小白学 AI：7 天从会聊天到会做事

一套面向普通人的中文 AI 入门课程。用 7 天完成从基础认知、提示词、AI 办公，到图片、视频、Agent 和智能工作流的第一次完整实践。

适合没有编程基础的职场人士、内容创作者、培训讲师和希望系统入门 AI 的学习者。

## 你将学会什么

- 理解 AI、生成式 AI、大模型、幻觉和多模态
- 写出包含背景、目标、要求和输出格式的提示词
- 用 AI 处理文章、会议记录、表格、周报和 PPT
- 生成和编辑图片，设计视频脚本与分镜
- 让 Agent 执行有边界的多步骤任务
- 用自然语言创建简单网页或工作工具
- 建立可重复、可检查的个人 AI 工作流

## 7 天课程

| 天数 | 主题 | 练习成果 |
| --- | --- | --- |
| 第 1 天 | AI 基础与工具选择 | 建立个人 AI 工具地图 |
| 第 2 天 | 提示词、对话与任务拆解 | 完成一项多轮任务 |
| 第 3 天 | AI 写作与内容表达 | 产出一篇可修改的初稿 |
| 第 4 天 | AI 学习与资料处理 | 生成摘要、分析和行动清单 |
| 第 5 天 | AI 办公与汇报 | 完成周报、表格或 PPT |
| 第 6 天 | 图片、视频与多模态创作 | 完成一组视觉内容或短片方案 |
| 第 7 天 | Agent、自然语言编程与结业项目 | 完成一个真实 AI 项目 |

## 开始学习

1. 阅读[完整课程书稿](小白学AI-7天自学与授课书稿.md)。
2. 按天完成讲解、操作示例、练习和课后作业。
3. 将自己的提示词、产出和修改记录保存到本地。
4. 第 7 天完成一个真实项目，并记录人工检查过程。

## 使用说明

课程示例中的工具名称和功能会随产品更新变化。学习时优先掌握任务拆解、信息核验、结果检查和权限控制等稳定方法，再根据自己能访问的工具完成练习。

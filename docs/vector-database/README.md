## 先记住三句话

- 向量数据库存储的是“可比较的语义表示”，不是自动理解业务的魔法数据库。
- 检索质量通常由数据切分、Embedding 模型、过滤条件、召回数量和重排共同决定。
- 企业级系统的关键不只是 Top-K 命中率，还包括权限隔离、可观测性、可回滚、成本和数据生命周期。

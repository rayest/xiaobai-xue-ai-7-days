# 向量数据库上线检查清单

## 数据与模型

- [ ] 原文有权威来源、唯一 ID、版本和删除事件
- [ ] 切分策略经过真实问题集评测
- [ ] Embedding 模型、维度、距离度量和语言范围已固定并记录
- [ ] 向量与原文的 `content_hash`、模型版本可追溯
- [ ] 失败重试幂等，重复写入不会产生脏副本

## 检索质量

- [ ] 有标注查询集，测 Recall@K、MRR/NDCG 和引用准确率
- [ ] 比较纯稠密、纯关键词、混合检索和重排
- [ ] 测试同义词、缩写、错别字、长问题、多语言和无答案问题
- [ ] 过滤、删除、更新和时间范围条件均有测试

## 安全与租户

- [ ] TLS、认证、最小权限和密钥轮换已启用
- [ ] 租户/部门/文档权限由服务端生成并强制注入
- [ ] 已做跨租户、缓存、重试、删除后的越权测试
- [ ] 查询、结果文档、管理员操作可审计，敏感内容已脱敏

## 可靠性与成本

- [ ] 副本、快照、恢复和跨区方案经过演练
- [ ] 有 P50/P95/P99、吞吐、内存、磁盘、空结果率和错误率告警
- [ ] 有模型升级、索引重建、schema 变更和回滚方案
- [ ] 明确 RPO/RTO、容量阈值、扩容方式和降级策略
- [ ] 已核算 Embedding、存储、索引、备份、流量和运维的总成本

## 运营闭环

- [ ] 用户反馈能回流为评测样本
- [ ] 错误答案、无依据回答和越权事件有处置流程
- [ ] 文档更新到可检索的端到端时延可观测
- [ ] 负责人、SLA、值班和故障复盘机制明确

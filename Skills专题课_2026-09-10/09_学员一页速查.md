# Agent Skills 一页速查

**记住：Skill 是可以复用的做事方法，必要时配套资料、模板和脚本。**

## 四步开始

1. 选任务：反复发生、规则相对稳定、你能判断结果。
2. 准备输入：脱敏的业务资料与一个合格样例。
3. 使用或创建 Skill：先做小的文字版本。
4. 换新材料测试：检查事实、缺项与冲突。

## Codex 调用

已安装且可发现时，在聊天输入框使用：

```text
$meeting-actions 整理素材/会议记录_标准.md，保存到练习输出/纪要.md。
```

找不到时，按路径读取：

```text
请读取 skills/meeting-actions/SKILL.md 及其引用格式，按规则整理指定材料。
```

第二种方式可以继续完成任务，但不证明原生自动发现成功。项目路径及发现方式见 [Codex 官方文档](https://learn.chatgpt.com/docs/build-skills)。

## 编写时填六项

使用情境｜输入｜输出｜关键判断｜按需资料｜验收方法。

## 验收时问五句

每条事实有来源吗？缺失项标出来了吗？冲突是否保留？是否做了未经授权的额外动作？新输入还能用吗？

## 容易混淆

Prompt 是本次要求；Skill 保存这类工作的做法；工具执行动作；知识库提供相关资料；插件可以分发扩展能力。装好 Skill 不代表工具、账号权限和数据都已准备好。

## 回去先做什么

只选一项每周任务，保存 Skill、两份脱敏输入和输出，再记一次人工修改耗时。不要只拿生成速度或下载量判断价值。

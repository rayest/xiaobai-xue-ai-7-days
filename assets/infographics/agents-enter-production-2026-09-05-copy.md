# 代理进入生产约束期

副标题：真正的竞争，从模型分数转向成本、边界与系统验证

## 01 价格看 token，决策看任务

- Astra 标准 API：$10 输入 / $50 输出（每百万 token）
- 单价约为 GPT-5.6 Sol 的 2.5 倍
- Fable 5.1 缓存读取降价 75%
- 行动｜记录每个成功任务的总成本与人工救援

## 02 开放生态进入控制权之争

- NVIDIA 拟以 129.303 亿美元收购 Hugging Face
- 平台覆盖 1800 万+开发者、300 万模型
- 官方承诺继续支持不同硬件、云和框架
- 行动｜持续检查跨硬件、跨云是否保持对等

## 03 代理把权限写进系统

- Commerce Agents 将购物与商家代理分开
- 参考实现不下单、不收费
- 商家写操作先暂存，必须由人批准
- 行动｜把审批、来源校验和回滚做成代码

## 04 AI 接入设备与公共服务

- MHS 用统一接口连接实验和制造设备
- 官方案例：集成与实验从数周缩到 8 小时
- WeatherNext 3 每小时刷新，图景约清晰 5 倍
- 行动｜物理动作默认最小权限、可中止、可审计

## 05 执行框架决定速度与安全

- 预执行工具链最高降低 44.9% 墙钟时间（特定基准）
- PlanFence 在 30 个受控流程中避免过期计划动作
- 技能蒸馏把仓库操作知识转为可复用能力
- 行动｜版本化计划、依赖、验证与失败回滚

底部总结：模型变强只是起点；能否安全完成整项工作，取决于模型之外的系统。

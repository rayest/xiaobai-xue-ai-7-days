## A. 本次新增

- 本轮未发现 OpenAI、Anthropic、Google、Microsoft、Meta、Mistral、阿里、字节、百度、智谱或 DeepSeek 发布新的旗舰模型或 API。
- 新增两条企业 Agent 治理与落地动态，均属于厂商自述，尚未经过独立效果审计。

## B. 今日持续升温

- 企业 Agent 的发现、身份、权限、连接器和运行时治理正在成为独立产品层。
- Agent 产品从通用助手进一步进入 Microsoft 365 治理、第三方风险管理等明确流程。

## C. AI 应用与产品方向变化

企业市场的竞争重点正在从“是否具备 Agent”转向“能否看见 Agent、限制 Agent、审计 Agent，并把判断性工作交还给人类”。

## D. 值得关注的模型、项目和平台

- `Orchestry AI & Agents`：面向 Microsoft 365 租户的 Agent 发现和治理功能。
- `ProcessUnity AI Agents for TPRM`：面向第三方风险管理流程的专用 Agent 套件。

## E. 对企业、开发者和产品经理的影响

企业需要同时建设 Agent 资产清单、所有者映射、连接器权限和人工审批规则；产品经理则应明确哪些步骤可自动执行，哪些判断必须由领域专家完成。

## F. 需要继续验证的问题

- 厂商披露的效率数据是否来自可复现、具有代表性的生产样本；
- Microsoft 365 Agent 治理是否覆盖外部 MCP、代码 Agent 和跨租户资源；
- 自动化风险处理是否会把错误判断放大到更多供应商和业务流程。

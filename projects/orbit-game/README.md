# ORBIT · 星环穿越

Three.js 3D 太空街机游戏。真实模型、星环光晕、陨石与能量收集、三次护盾、逐渐加速、暂停/重试、可切换音效，以及本地最高分。支持键盘与手机触控。

## 运行

```sh
npm install
npm run dev
```

打开终端输出的本地地址。需要支持 WebGL 2 的现代浏览器。

```sh
npm test
npm run build
npm run preview
```

`dist/` 是构建产物，可托管到静态网站服务。

## 操作

- A / D 或左右方向键：切换三条航道。
- 按住 Shift / W / ↑ 主动加速；松开恢复巡航。也可点击屏幕加速按钮切换，最高为巡航速度的 2.25 倍。
- 星点、星环和周边陨石随实际速度相对运动，加速时出现星光拖尾、视角拉伸和更长的尾焰。
- 持续引擎声与气流声随速度变化，收集、碰撞和变道有提示音；暂停时引擎静音。
- 空格 / 右上角暂停按钮：暂停或继续。切换标签页自动暂停。
- 手机：轻触左右按钮或在画面上左右滑动。
- 绿色晶体 +100 分，存活每秒 +10 分。撞击陨石损失一个护盾，护盾耗尽后结算。
- 右上角声音按钮开启或关闭合成音效，点击开始后默认开启。

## 项目结构

- `src/scene.js`：Three.js 几何模型、灯光、后期光晕和场景。
- `src/main.js`：游戏循环、状态、输入、音效及界面。
- `src/rules.js`：碰撞、积分和难度规则；对应 Node 单元测试。
- `src/style.css`：桌面与手机样式。
- `public/nebula.png`：内置 Image Gen 生成的背景。
- `design/`：设计参考与验证记录。

Three.js 场景结构参考：[官方 Creating a scene 文档](https://threejs.org/manual/en/creating-a-scene.html)。无需后端或 API 密钥。

## 外星交战模式

- 飞船自动发射青色激光，变道瞄准外星战机；敌方红色弹幕需躲避。
- 敌机在第 3 秒出现，后续形成双机编队；击毁一架 +250 分。
- 第 25 秒出现外星母舰，此后按 45 秒间隔出现（上一个 Boss 存活时不会叠加）。
- 母舰有 24 点生命、横向移动和双航道弹幕；始终留有一条未发射弹幕的航道。
- 击毁母舰 +2000 分并修复一格护盾；加速同时提高自动射速。
- 新增激光、爆炸音效及爆炸碎片，HUD 和结算显示击毁数量。

`src/combat.js` 管理敌机、弹幕、激光和爆炸，复用几何资源；超出视野的弹丸和过期碎片会清理。战斗测试覆盖跨帧命中、敌机击毁、Boss 生成及击破、敌弹伤害和重置。

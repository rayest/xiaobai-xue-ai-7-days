# ORBIT visual specification

Concept: `concept.png`, 1536 × 1024. Built-in Image Gen concept and separate production nebula pass.

Full-bleed dark teal space (#050e10), ivory typography (#e9e3ca), acid lime accent (#d3f434), muted thin structural rules. Header is an open horizontal rail; intro is left aligned; orbital ring and spacecraft dominate the right. Footer carries input hints. Main title scales to 112px, header wordmark uses wide letter spacing. Lime clipped-corner CTA, outlined square sound/pause buttons. No cards.

Allowed intro copy: ORBIT, 星环穿越, 驾驶飞船，穿过星环。避开陨石，把能量带回家。, 开始飞行, 最佳成绩, A D / ← → 移动, 空格 暂停, 收集能量 +100.

Intentional deviations: the concept's fictional best score is replaced by actual saved player score; all ships, rocks, rings and crystals are real Three.js geometries, to support the requested 3D game, with generated nebula as background. Mobile moves the introduction below the 3D focal point and uses real touch controls. Gameplay and pause/end overlays extend the same typography, palette and component system. Asset lighting and mesh silhouette are approximations of the concept, not baked raster artwork.

Generation briefs: full primary game screen with dark teal cosmos, lime orbital ring, low-poly white spacecraft, native Chinese HTML UI; separate text-free, almost-black teal nebula and sparse distant stars for the background layer. Both generated with the built-in Image Gen tool.

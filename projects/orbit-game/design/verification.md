## 实际交互

- 开始飞行：HUD 显示初始分数、速度和三个护盾。
- 能量收集：可见分数增加、+100 提示。
- 陨石碰撞：三个护盾逐步耗尽，出现受损提示和结算。
- 暂停：分数固定为 000348，恢复后继续增长；按钮和空格均验证。
- 手机触控：中航道可切至右航道，再返回中航道。
- 键盘：ArrowLeft 将中航道切至左航道。
- 结算：本次 357 分、1 个能量、25 秒；本地最佳分同步更新。
- 再次出发：护盾恢复三个、得分从零重新计算。
- 音效开关：aria-pressed 切换为 true，测试后关闭。
- 页面控制台：未记录 error / warn。

`npm test`：4 项通过，覆盖航道边界、跨帧碰撞、相邻航道安全、得分与难度上限。

`npm run build`：通过。Three.js 单独打包，消除初始单文件体积警告。
